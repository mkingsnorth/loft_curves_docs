Debug Mode
===============================

The **Debug Mode** option helps you identify and correct issues with guide or profile curves when a lofted surface doesn’t behave as expected.

When enabled in the Loft Curves modifier, curves are colour-coded directly in the viewport, showing the order and direction in which they’re being processed.  
Problem curves — such as flipped or misaligned ones — are easy to spot and fix. Once corrected, simply turn off Debug Mode to return to the normal shaded view.
