Custom Ordering
===============================

The **Custom Ordering** option lets you manually define the sequence in which curves are lofted — perfect for fine-tuning complex shapes.

When enabled in the Loft Curves modifier, each curve can be given a numerical order value using the **Assign Curve Order Modifier** button found under *Curve Tools*.  
This allows precise control over the loft sequence, rather than relying on automatic XYZ sorting.
